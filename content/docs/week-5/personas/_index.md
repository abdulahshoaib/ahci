# Personas

Personas are fictional but evidence-based user profiles. They summarize important user goals, behaviors, needs, frustrations, and context.

## Purpose

- Keep design focused on users.
- Communicate user differences to team.
- Support design decisions and prioritization.
- Prevent designing only for generic or imagined users.

## Design Implication

Personas should be based on research. Unsupported personas can reinforce assumptions instead of reducing them.
