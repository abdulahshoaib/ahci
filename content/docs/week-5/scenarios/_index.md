# Scenarios

Scenarios describe how users might interact with a system in a specific situation. They connect user goals, context, actions, and system responses.

## Uses

- Explore user tasks.
- Communicate design ideas.
- Identify requirements.
- Compare alternative workflows.
- Support evaluation and walkthroughs.

## Design Implication

Good scenarios include user context and motivation, not only interface steps.
