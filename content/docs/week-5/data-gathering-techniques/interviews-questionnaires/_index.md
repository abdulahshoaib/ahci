# Interviews & Questionnaires

Interviews and questionnaires collect user opinions, experiences, goals, and problems. Interviews provide depth; questionnaires provide wider reach.

## Interviews

- Useful for exploring needs and motivations.
- Can be structured, semi-structured, or unstructured.
- Allow follow-up questions.

## Questionnaires

- Useful for collecting responses from many people.
- Good for ratings, preferences, and demographic data.
- Need clear, unbiased questions.

## Design Implication

Use interviews when problem is unclear. Use questionnaires when questions are already well-defined.
