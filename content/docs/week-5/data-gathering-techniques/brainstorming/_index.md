# Brainstorming

Brainstorming generates many ideas before selecting or judging solutions. It can support requirement discovery by exploring possible needs, features, constraints, and design directions.

## Good Practice

- Separate idea generation from evaluation.
- Encourage varied ideas.
- Build on others' ideas.
- Use prompts from user research.
- Cluster ideas after session.

## Design Implication

Brainstorming should be grounded in user evidence. Without research, it can produce attractive but irrelevant ideas.
