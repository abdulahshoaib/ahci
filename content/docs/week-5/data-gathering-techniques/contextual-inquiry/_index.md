# Contextual Inquiry

Contextual inquiry combines observation and interview in user's real context. Designer watches user perform work and asks questions while activity happens.

## Principles

- Study work in context.
- Treat user as expert.
- Ask about real actions, not imagined behavior.
- Interpret findings with user where possible.

## Design Implication

Contextual inquiry is useful when workflow, environment, tools, or interruptions strongly affect interaction.
