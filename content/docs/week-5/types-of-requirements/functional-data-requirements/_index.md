# Functional & Data Requirements

Functional requirements describe what system must do. Data requirements describe what information system must store, process, display, collect, or exchange.

## Functional Requirements

- User actions system must support.
- System behaviors and responses.
- Tasks, workflows, and operations.
- Rules that control system behavior.

## Data Requirements

- Data fields and formats.
- Data sources and ownership.
- Storage and retrieval needs.
- Privacy, security, and accuracy needs.

## Example

Course registration system must let student search courses, add course to cart, validate prerequisites, and store enrollment records.
