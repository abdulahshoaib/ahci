# User & Environment Requirements

User requirements describe target users, abilities, goals, knowledge, preferences, and limitations. Environment requirements describe physical, social, organizational, and technical context where system will be used.

## User Requirements

- User roles and experience levels.
- Accessibility needs.
- Domain knowledge.
- Goals, motivations, and pain points.

## Environment Requirements

- Devices and network conditions.
- Lighting, noise, mobility, and interruptions.
- Workplace rules and organizational constraints.
- Social context and collaboration needs.

## Design Implication

Same feature may need different design depending on user ability and use environment.
