# Use Cases

Use cases describe interactions between an actor and a system to achieve a goal. They define expected flow, alternative flows, and exceptions.

## Elements

- Actor.
- Goal.
- Preconditions.
- Main success scenario.
- Alternative flows.
- Exceptions.
- Postconditions.

## Design Implication

Use cases help clarify functional requirements, but they should be combined with user research to avoid overly system-centered design.
