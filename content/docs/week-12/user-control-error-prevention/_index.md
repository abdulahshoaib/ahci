# User Control and Error Prevention

User control means users can direct, cancel, reverse, and understand system actions. Error prevention means design reduces avoidable mistakes before they happen.

## Techniques

- Undo and redo.
- Cancel and back actions.
- Clear confirmation for risky actions.
- Constraints and validation.
- Helpful defaults.
- Visible system state.

## Design Implication

Users trust systems more when they can recover and when system prevents dangerous mistakes.
