# Quantitative vs Qualitative Evaluation

Quantitative evaluation uses numbers. Qualitative evaluation uses observations, explanations, and interpretation.

## Quantitative

- Task time.
- Success rate.
- Error count.
- Ratings and scores.

## Qualitative

- User comments.
- Observed confusion.
- Interview themes.
- Reasons behind behavior.

## Design Implication

Quantitative data shows what happened. Qualitative data helps explain why.
