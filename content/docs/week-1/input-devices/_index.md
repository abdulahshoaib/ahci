# Input Devices

Input devices allow users to send commands, data, movement, and signals to a computer. The choice of input device affects speed, accuracy, accessibility, fatigue, and the kinds of interactions a system can support.

## Common Input Devices

- Keyboard
- Mouse
- Touchscreen
- Stylus
- Microphone
- Camera
- Game controller
- Sensors and wearables

## HCI Considerations

Designers should consider precision, user posture, environment, accessibility, learning effort, and error rates when choosing or designing for input methods.
