# The Computer and Interaction

Human-computer interaction depends on both human capabilities and computer capabilities. The computer receives input, processes information, stores data, communicates through networks, and produces output that users can interpret.

## Interaction Loop

1. The user forms a goal.
2. The user performs an action through an input device.
3. The computer processes the action.
4. The system changes state.
5. The computer presents output.
6. The user interprets the feedback.

## Design Concern

The interface should make this loop clear, fast, and recoverable. Delays, missing feedback, or confusing output can break the user's understanding of the system.
