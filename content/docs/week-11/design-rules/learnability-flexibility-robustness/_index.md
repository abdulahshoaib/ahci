# Learnability, Flexibility, and Robustness

Learnability, flexibility, and robustness are major usability rule categories.

## Learnability

System should be easy to start using and understand.

## Flexibility

System should support different users, strategies, and paths to same goal.

## Robustness

System should help users recover, understand state, and complete work reliably.

## Design Implication

Good systems help beginners learn, experts move fast, and all users recover from problems.
