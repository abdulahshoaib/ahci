# Shneiderman's 8 Golden Rules

Shneiderman's rules summarize practical guidance for interactive systems.

## Rules

1. Strive for consistency.
2. Enable frequent users to use shortcuts.
3. Offer informative feedback.
4. Design dialogs to yield closure.
5. Prevent errors and provide simple handling.
6. Permit easy reversal of actions.
7. Keep users in control.
8. Reduce short-term memory load.

## Design Implication

Rules emphasize consistency, control, feedback, error recovery, and reduced mental effort.
