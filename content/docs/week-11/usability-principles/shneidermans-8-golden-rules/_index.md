# Shneiderman’s 8 Golden Rules

Shneiderman's 8 Golden Rules are broad design rules that help designers create usable, efficient, and user-friendly interfaces.

They act as a practical checklist for evaluating interface designs and improving usability.

## 1. Strive for Consistency

Keep interface elements, terminology, commands, layouts, and behaviors uniform throughout the system.

Users should not have to relearn the interface when moving between different parts of the system.

### Examples

- Similar buttons should look and behave the same.
- The same action should always produce the same result.
- Menus should follow a consistent structure.

## 2. Enable Frequent Users to Use Shortcuts

Provide accelerators that allow experienced users to perform tasks more quickly.

Shortcuts increase efficiency without affecting beginners.

### Examples

- Keyboard shortcuts such as Ctrl + C and Ctrl + V
- Command aliases
- Auto-complete features
- Macros

## 3. Offer Informative Feedback

The system should always inform users about what is happening.

Every user action should produce appropriate feedback.

### Examples

- Progress bars during downloads
- Success messages after saving
- Highlighting selected items
- Loading indicators

## 4. Design Dialogs to Yield Closure

Tasks should have a clear beginning, middle, and end.

Users should know when a process has been completed successfully.

### Examples

- Order confirmation page after checkout
- "File uploaded successfully" message
- Installation completed screen

## 5. Offer Error Prevention and Simple Error Handling

Design interfaces that prevent errors whenever possible and provide clear guidance when errors occur.

### Examples

- Input validation
- Disabled invalid options
- Confirmation before deletion
- Clear error messages with solutions

## 6. Permit Easy Reversal of Actions

Users should be able to recover easily from mistakes.

This encourages exploration and reduces anxiety.

### Examples

- Undo and Redo
- Recycle Bin
- Version history
- Cancel buttons

## 7. Support Internal Locus of Control

Users should feel that they are controlling the system rather than the system controlling them.

The interface should respond to user actions and avoid unexpected behavior.

### Examples

- User chooses navigation paths
- User controls task sequence
- User starts and stops processes when desired

## 8. Reduce Short-Term Memory Load

Interfaces should minimize the amount of information users must remember.

Recognition should be preferred over recall.

### Examples

- Visible menus
- Icons with labels
- Recently used files lists
- Auto-filled forms

## Areas of Application

| Category | Golden Rules |
|-----------|-------------|
| Interface Design | Strive for Consistency, Enable Frequent Users to Use Shortcuts, Offer Informative Feedback |
| User Support | Design Dialogs to Yield Closure, Offer Error Prevention and Simple Error Handling |
| User Experience | Permit Easy Reversal of Actions, Support Internal Locus of Control, Reduce Short-Term Memory Load |

## Benefits

Following the Golden Rules helps create systems that are:

- Easy to learn
- Safe to use
- Efficient
- User friendly
- Error tolerant
- Predictable
