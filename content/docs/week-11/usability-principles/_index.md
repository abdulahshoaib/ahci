# Usability Principles

Usability principles are general rules for making systems easier to learn, use, and recover from.

## Common Concerns

- Visibility.
- Feedback.
- Consistency.
- Error prevention.
- Recovery.
- User control.
- Match with user expectations.

## Design Implication

Principles help identify design problems before and after user testing.
