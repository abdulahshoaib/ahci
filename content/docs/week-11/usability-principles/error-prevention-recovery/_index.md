# Error Prevention and Recovery

Error prevention reduces chance of mistakes. Recovery helps users fix problems when mistakes happen.

## Techniques

- Constraints and validation.
- Clear labels and defaults.
- Confirmation for destructive actions.
- Undo and redo.
- Helpful error messages.
- Preserve user input after errors.

## Design Implication

Good systems assume human error and design recovery paths before users need them.
