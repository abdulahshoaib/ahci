# Norman's 7 Principles

Norman's principles help bridge gap between user goals and system behavior.

## Principles

1. Use knowledge in world and head.
2. Simplify task structure.
3. Make things visible.
4. Get mappings right.
5. Exploit constraints.
6. Design for error.
7. Standardize when needed.

## Design Implication

Interfaces should make actions understandable and outcomes interpretable.
