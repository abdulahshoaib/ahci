# Interface Consistency and Feedback

Consistency makes similar things behave similarly. Feedback shows system response to user action.

## Consistency

- Same labels for same concepts.
- Same controls for same actions.
- Same layout patterns across screens.

## Feedback

- Confirm action received.
- Show progress.
- Report success or failure.
- Explain next step.

## Design Implication

Consistency supports prediction. Feedback supports understanding and trust.
