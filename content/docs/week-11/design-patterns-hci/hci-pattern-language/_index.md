# HCI Pattern Language

HCI pattern language is organized collection of patterns that work together. It gives designers shared vocabulary for common interface problems.

## Pattern Parts

- Problem.
- Context.
- Forces or constraints.
- Solution.
- Consequences.
- Related patterns.

## Design Implication

Pattern language helps teams discuss design at reusable level instead of treating each screen as isolated.
