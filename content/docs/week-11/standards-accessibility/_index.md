# Standards and Accessibility

Standards define required or recommended rules for compatibility, safety, quality, and accessibility. Accessibility ensures people with different abilities can use system.

## Concerns

- Keyboard access.
- Screen reader support.
- Colour contrast.
- Captions and alternatives.
- Clear structure and labels.
- WCAG-style accessibility requirements.

## Design Implication

Accessibility should be designed from start, not added late as patch.
