# User-Centered Usability Design

User-centered usability design applies usability principles through research, prototyping, and evaluation with users.

## Process

1. Understand users and context.
2. Define usability goals.
3. Create design alternatives.
4. Prototype.
5. Evaluate.
6. Iterate.

## Design Implication

Rules guide design, but user evidence confirms whether design works in real use.
