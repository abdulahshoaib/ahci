# KLM & GOMS

GOMS models user tasks as goals, operators, methods, and selection rules. KLM estimates expert task time using keystroke-level actions.

## Uses

- Compare task flows.
- Estimate efficiency.
- Identify unnecessary steps.
- Analyze expert performance.

## Design Implication

KLM and GOMS help evaluate efficiency before implementation, but they do not capture emotion, confusion, or broader UX.
