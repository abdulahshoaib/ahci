# Analytical Methods

Analytical methods evaluate design through expert inspection, walkthroughs, or predictive models.

## Examples

- Heuristic evaluation.
- Cognitive walkthrough.
- Fitts's Law.
- KLM and GOMS.

## Design Implication

Analytical methods are useful early, but should not fully replace user evidence.
