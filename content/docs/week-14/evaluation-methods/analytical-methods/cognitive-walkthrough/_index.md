# Cognitive Walkthrough

Cognitive walkthrough evaluates how easily new users can learn to complete tasks.

## Questions

- Will user know what to do?
- Will user see correct action?
- Will user understand action label?
- Will feedback show progress?

## Design Implication

Cognitive walkthrough is useful for learnability and first-time use.
