# Evaluation Methods

Evaluation methods can be empirical or analytical.

## Empirical

Empirical methods collect data from users or real use.

## Analytical

Analytical methods inspect or model design without necessarily testing with users.

## Design Implication

Use empirical methods to see real behavior. Use analytical methods to find likely problems earlier or cheaper.
