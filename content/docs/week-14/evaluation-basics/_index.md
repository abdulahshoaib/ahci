# Evaluation Basics

Evaluation checks whether interface supports users, tasks, and goals. It can happen before, during, or after implementation.

## Purposes

- Find usability problems.
- Compare design alternatives.
- Measure performance.
- Understand user experience.
- Guide iteration.

## Design Implication

Evaluation should answer clear questions. Method choice depends on what team needs to learn.
