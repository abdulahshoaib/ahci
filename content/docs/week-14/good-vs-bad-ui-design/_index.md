# Good vs Bad UI Design

Good UI design supports user goals clearly and efficiently. Bad UI design creates confusion, errors, delay, or mistrust.

## Good UI

- Clear hierarchy.
- Visible actions.
- Consistent behavior.
- Useful feedback.
- Accessible interaction.

## Bad UI

- Hidden actions.
- Clutter.
- Poor labels.
- Weak feedback.
- Error-prone flows.

## Design Implication

Evaluation should connect UI quality to user task success, not only appearance.
