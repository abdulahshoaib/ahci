# User-Centered Design Principles

User-centered design keeps user goals, tasks, abilities, and context central throughout design.

## Principles

- Study users early.
- Define real needs.
- Prototype alternatives.
- Evaluate with users.
- Iterate based on evidence.

## Design Implication

User-centered design prevents teams from optimizing for internal assumptions instead of real users.
