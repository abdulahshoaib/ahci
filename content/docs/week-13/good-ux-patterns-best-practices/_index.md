# Good UX Patterns and Best Practices

Good UX patterns solve common problems clearly and ethically.

## Practices

- Clear navigation.
- Strong visual hierarchy.
- Helpful feedback.
- Recoverable errors.
- Accessible forms.
- Responsive layouts.
- Transparent choices.

## Design Implication

Best practices are starting points. Validate them against users, tasks, and context.
