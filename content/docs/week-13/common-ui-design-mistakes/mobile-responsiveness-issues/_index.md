# Mobile Responsiveness Issues

Mobile responsiveness issues appear when interface does not adapt to smaller screens, touch input, or mobile context.

## Problems

- Horizontal scrolling.
- Tiny tap targets.
- Overlapping content.
- Hidden navigation.
- Slow loading.
- Forms hard to complete.

## Design Implication

Mobile design must account for screen size, touch, movement, attention, and network conditions.
