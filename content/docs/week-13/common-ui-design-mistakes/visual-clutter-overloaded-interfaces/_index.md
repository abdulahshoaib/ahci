# Visual Clutter and Overloaded Interfaces

Visual clutter happens when too many elements compete for attention. Overloaded interfaces make users decide what matters without clear guidance.

## Causes

- Too many buttons.
- Dense text blocks.
- Competing colours.
- Repeated banners and popups.
- No clear priority.

## Design Implication

Reduce clutter by prioritizing tasks, grouping related items, and removing low-value elements.
