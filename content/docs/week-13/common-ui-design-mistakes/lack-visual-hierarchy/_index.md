# Lack of Visual Hierarchy

Visual hierarchy shows what is important and what users should notice first.

## Problems

- Everything same size.
- Weak headings.
- Important actions hidden.
- No contrast between primary and secondary content.
- Poor spacing between sections.

## Design Implication

Hierarchy guides attention. Without it, users must inspect everything manually.
