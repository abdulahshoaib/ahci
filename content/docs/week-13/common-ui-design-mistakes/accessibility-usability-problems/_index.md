# Accessibility and Usability Problems

Accessibility problems prevent people with different abilities from using interface. Many accessibility fixes also improve general usability.

## Problems

- Missing alt text.
- Poor keyboard support.
- Low contrast.
- Unlabeled form fields.
- Colour-only status.
- Confusing focus order.

## Design Implication

Accessible design expands usable audience and reduces avoidable barriers.
