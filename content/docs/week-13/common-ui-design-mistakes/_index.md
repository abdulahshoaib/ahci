# Common UI Design Mistakes

Common UI mistakes reduce clarity, trust, accessibility, and task success.

## Categories

- Poor navigation.
- Visual clutter.
- Readability problems.
- Weak hierarchy.
- Mobile failures.
- Accessibility gaps.

## Design Implication

Most mistakes come from ignoring user goals, context, and constraints.
