# Poor Navigation & Information Architecture

Poor navigation and information architecture make users lose orientation and fail to find content.

## Problems

- Unclear labels.
- Too many menu items.
- Deep hidden hierarchy.
- Missing search or filters.
- Inconsistent navigation placement.

## Design Implication

Navigation should match user mental models and common tasks, not internal organization only.
