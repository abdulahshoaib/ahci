# Conversion and Engagement Issues

Conversion and engagement problems happen when users do not complete intended actions or return to product.

## Causes

- Weak value communication.
- Poor onboarding.
- Long forms.
- Slow pages.
- Low trust.
- Confusing calls to action.

## Design Implication

Improving conversion should not rely on manipulation. Better clarity, trust, speed, and task support usually help more sustainably.
