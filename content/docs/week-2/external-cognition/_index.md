# External Cognition

External Cognition is concerned with understanding how people interact with external representations such as maps, notes, diagrams, calendars, and other artifacts.

It examines the cognitive benefits of external representations, the processes involved in using them, and how they help extend human thinking and problem solving.

External cognition also explores how technology can be designed to support complex activities such as learning, problem solving, and decision making.

## Externalizing to Reduce Memory Load

People often use external representations to reduce the amount of information they must remember.

Examples include:

- Diaries
- Calendars
- Notes
- Shopping lists
- To-do lists
- Reminders

These representations can:

- Remind people that something needs to be done.
- Remind people what needs to be done.
- Remind people when something needs to be done.

### Example

A calendar reminder for Mother's Day can remind a person to buy and send a card before a specific date.

## Computational Offloading

Computational offloading occurs when people use external tools to perform calculations or other mental tasks.

Examples include:

- Pen and paper
- Calculators
- Spreadsheets

Using these tools reduces cognitive effort and allows people to solve problems more efficiently.

### Example

Multiplying large numbers is easier with a calculator or written working than performing the calculation entirely in memory.

## Annotation

Annotation involves modifying an existing representation by making marks on it.

Examples include:

- Underlining
- Highlighting
- Crossing off items
- Ticking completed tasks

Annotation helps people organize and track information.

## Cognitive Tracing

Cognitive tracing involves physically manipulating external representations to support thinking.

Examples include:

- Rearranging Scrabble tiles
- Organizing playing cards
- Moving notes into different groups

This allows people to explore possibilities without relying entirely on memory.

## Design Implications

Interfaces should provide external representations that reduce memory load and support computational offloading.

### Example

Information visualizations can help users understand large amounts of data and make decisions more quickly than relying on memory alone.
