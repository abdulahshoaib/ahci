# External Cognition

External cognition is the use of external objects, representations, and tools to support thinking. People often reduce mental effort by writing things down, arranging objects, drawing diagrams, or using visual displays.

## Functions

- Reducing memory load.
- Supporting comparison and calculation.
- Making abstract relationships visible.
- Helping users plan, track, and revise work.

## Example

A calendar externalizes memory by showing appointments, deadlines, and free time instead of requiring the user to remember everything internally.
