# Mental Models

A mental model is a user's internal understanding of how a system works. Users rely on mental models to predict what actions are possible and what results those actions will produce.

## Good Mental Models

Good interfaces help users build accurate mental models through consistent behavior, clear labels, visible state, and meaningful feedback.

## Poor Mental Models

When the interface behaves unexpectedly or hides important system logic, users may form incorrect assumptions and make repeated mistakes.

## Example

If deleting a photo from one device also deletes it from cloud storage, the interface must make that relationship clear so users understand the consequence.
