# Cognitive Aspects

Cognitive aspects of HCI focus on how people think, understand, remember, learn, decide, and act while using interactive systems. A usable interface must fit human cognitive abilities instead of assuming perfect attention, memory, or reasoning.

## Why Cognition Matters

- Users have limited attention.
- Users interpret interfaces through prior knowledge.
- Users make mistakes when tasks overload memory or perception.
- Users learn faster when systems are predictable and meaningful.

## Design Implication

Interfaces should reduce unnecessary mental effort, make important information visible, provide clear feedback, and support users in forming accurate expectations.
