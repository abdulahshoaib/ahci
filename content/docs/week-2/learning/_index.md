# Learning

Learning in HCI is the process by which users become able to understand and operate a system more effectively. Systems are easier to learn when they match user expectations, use consistent patterns, and provide helpful feedback.

## Supporting Learning

- Use familiar concepts and terminology.
- Keep core actions visible.
- Provide clear feedback after each action.
- Make errors recoverable.
- Introduce complexity gradually.

## Design Implication

A learnable system lets new users begin successfully while still supporting faster, more advanced use over time.
