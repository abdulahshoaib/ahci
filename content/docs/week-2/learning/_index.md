# Learning

Learning involves the accumulation of knowledge and skills and relies heavily on memory.

## Types of Learning

### Incidental Learning

Learning that occurs without deliberate effort.

#### Examples

- Recognizing people's faces.
- Remembering what happened during the day.

### Intentional Learning

Learning that occurs through conscious effort.

#### Examples

- Studying for an exam.
- Learning how to cook.

Intentional learning is generally more difficult than incidental learning.

## Technology and Learning

Many technologies have been developed to support learning, including:

- Multimedia systems
- Animations
- Virtual Reality (VR)

These technologies can help users understand and retain information more effectively.

## Learning by Doing

People often find it difficult to learn by following instructions in manuals.

In general, users prefer learning through direct interaction and experience rather than reading instructions.

### Example

A user is more likely to learn how to use a new application by exploring its features than by reading a lengthy user manual.

## Design Implications

- Design interfaces that encourage exploration.
- Design interfaces that guide and constrain learners when necessary.
- Dynamically link concepts and representations to help users understand complex material.
