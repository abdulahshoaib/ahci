# Memory

Memory allows users to retain information, recognize patterns, and use prior experience. Human memory is powerful but limited, especially when users must remember exact commands, codes, steps, or hidden rules.

## Types of Memory

- **Sensory memory:** Brief retention of sensory input.
- **Working memory:** Temporary mental workspace for active tasks.
- **Long-term memory:** Stored knowledge, skills, and experiences.

## Design Implication

Interfaces should favor recognition over recall. Menus, labels, previews, defaults, and visible options reduce the need for users to remember information from scratch.
