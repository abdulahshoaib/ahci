# Interface Metaphors

Interface metaphors use familiar real-world or digital concepts to help users understand new systems. Examples include desktop, folder, trash, cart, and timeline.

## Benefits

- Support learning.
- Make abstract functions concrete.
- Build on existing mental models.

## Risks

- Metaphor may not fit all actions.
- Users may expect behavior that system does not support.
- Cultural differences can affect interpretation.

## Design Implication

Use metaphors as aids, not cages. Break metaphor when usability requires clearer behavior.
