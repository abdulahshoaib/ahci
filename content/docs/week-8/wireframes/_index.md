# Wireframes

A wireframe is a low-fidelity visual representation of a user interface that focuses on structure, functionality, and layout rather than visual appearance.

Wireframes are used to show how information and interface elements are arranged on a screen before detailed visual design begins. They help designers, developers, and stakeholders understand how users will navigate and interact with a system.

Wireframes do not focus on colors, graphics, typography, or branding. Instead, they emphasize the organization of content and interface components.

## What a Wireframe Shows

A wireframe typically illustrates:

- Screen structure
- Placement of interface elements
- Navigation components
- Information hierarchy
- User interaction flow

## Common Elements in Wireframes

| Element | Purpose |
|----------|---------|
| Buttons | Trigger actions |
| Menus | Provide navigation options |
| Navigation Bars | Support movement between screens |
| Input Fields | Accept user input |
| Content Areas | Display information |
| Labels and Placeholders | Indicate expected content |

## Rules of Wireframing

### No Color

Wireframes use only grayscale colors such as:

- White
- Black
- Gray

This keeps attention focused on layout and functionality.

### Use Placeholders

Instead of actual content:

- Images are represented by boxes containing an "X"
- Text is represented by simple lines or placeholder text

Example:

```text
+------------------+
|        X         |
|      Image       |
+------------------+

---------------
---------------
---------------
```

### Use Standard Symbols

Common interface symbols are used to represent familiar functions.

Examples:

- 🔍 Search
- ☰ Menu
- ← Back
- → Next

## Why Wireframes Are Important

Wireframes help designers:

- Translate scenarios and storyboards into interface screens
- Focus on usability rather than aesthetics
- Identify navigation problems early
- Quickly iterate on design ideas
- Communicate designs to developers and stakeholders

## Wireframes vs. Final Design

| Wireframe | Final Interface |
|------------|----------------|
| Focuses on structure | Focuses on appearance and interaction |
| Uses grayscale | Uses colors, typography, and branding |
| Low-fidelity | High-fidelity |
| Easy to modify | More expensive to change |
| Supports early design exploration | Represents the finished product |

Wireframes act as a bridge between conceptual design ideas and detailed interface implementation.
