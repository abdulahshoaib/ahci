# Wireframes

Wireframes are simplified layouts showing page structure, content priority, navigation, and interaction zones. They usually avoid detailed visual styling.

## Uses

- Plan layout.
- Discuss information hierarchy.
- Test flow before visual design.
- Align team and stakeholders.

## Design Implication

Wireframes help evaluate structure before color, typography, and branding distract from core interaction.
