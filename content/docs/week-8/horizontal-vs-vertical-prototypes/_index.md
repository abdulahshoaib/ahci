# Horizontal vs Vertical Prototypes

Horizontal and vertical prototypes differ in scope and depth.

## Horizontal Prototype

Horizontal prototype covers broad set of features with shallow functionality. It is useful for exploring navigation, layout, and overall structure.

## Vertical Prototype

Vertical prototype implements narrow feature deeply. It is useful for testing complex interaction, data flow, or technical feasibility.

## Design Implication

Use horizontal prototypes to test breadth. Use vertical prototypes to test depth.
