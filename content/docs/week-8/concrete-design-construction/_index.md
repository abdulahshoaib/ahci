# Concrete Design and Construction

Concrete design turns concepts and prototypes into detailed interface decisions and buildable artifacts. It includes layout, controls, content, states, interaction flows, and implementation constraints.

## Activities

- Define screens and components.
- Specify interaction behavior.
- Create detailed prototypes.
- Prepare assets and content.
- Coordinate with implementation.

## Design Implication

Concrete design should preserve user goals discovered earlier while resolving practical details needed for construction.
