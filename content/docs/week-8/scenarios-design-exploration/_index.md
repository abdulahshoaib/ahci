# Scenarios and Design Exploration

Scenarios describe possible user situations and interactions. Design exploration uses scenarios, sketches, prototypes, and critique to compare alternatives.

## Uses

- Understand context.
- Explore workflows.
- Reveal assumptions.
- Compare design options.
- Support evaluation before implementation.

## Design Implication

Scenarios keep design grounded in user goals and real situations while teams explore multiple possible solutions.
