# Index Card Prototyping

Index card prototyping uses separate cards to represent screens, states, content chunks, or interaction steps. Cards can be rearranged quickly during design sessions.

## Uses

- Explore navigation.
- Organize information architecture.
- Test task flow.
- Support participatory design.

## Design Implication

Index cards make structure flexible, so teams can revise flow without committing to visual layout.
