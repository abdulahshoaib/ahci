# Wizard-of-Oz Prototyping

Wizard-of-Oz prototyping simulates system behavior manually while users believe they are interacting with an automated system.

## Uses

- Test AI or speech interfaces before full implementation.
- Explore interaction flow.
- Study user expectations.
- Evaluate value of automation.

## Design Implication

This method is useful for risky or expensive features, but participants must be debriefed ethically when deception is involved.
