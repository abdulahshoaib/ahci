# Storyboards

A storyboard is a series of sketches or panels that show how a user progresses through a task while interacting with a product or system.

Storyboards are commonly used in low-fidelity prototyping to visualize user activities, system interactions, and outcomes before development begins. They are often used alongside scenarios to add more detail and support role-playing activities.

A storyboard helps designers understand:

- How users interact with a system
- The sequence of actions performed
- The context in which interaction occurs
- The system's responses to user actions

## Elements of a Storyboard

Each storyboard panel typically includes:

| Element | Description |
|----------|-------------|
| User | The person interacting with the system |
| Context | The environment or situation in which interaction occurs |
| Interaction | The action performed by the user |
| System Response | The result or feedback provided by the system |

## Benefits of Storyboards

- Visualize user journeys step-by-step
- Explore design ideas before implementation
- Support communication among stakeholders
- Identify usability issues early
- Encourage discussion and feedback

## Example 1: Food Delivery App

| Panel | Description |
|---------|-------------|
| 1 | Ali has a 30-minute break, feels hungry, and takes out his phone |
| 2 | Ali opens the food delivery application |
| 3 | He browses nearby restaurants and available meals |
| 4 | Ali selects a burger and taps the "Order" button |
| 5 | The app confirms the order and shows an estimated delivery time of 20 minutes |

## Example 2: ATM Withdrawal

| Panel | Description |
|---------|-------------|
| 1 | User approaches the ATM |
| 2 | User inserts the bank card |
| 3 | User enters the PIN |
| 4 | User selects "Withdraw Cash" |
| 5 | ATM dispenses money and displays a confirmation message |

## Example 3: University LMS

| Panel | Description |
|---------|-------------|
| 1 | Student opens the LMS website |
| 2 | Student logs into their account |
| 3 | Student navigates to the course page |
| 4 | Student downloads lecture notes |
| 5 | System displays a successful download notification |

Storyboards focus on the flow of interaction rather than visual design details, making them an effective tool for early-stage design exploration.
