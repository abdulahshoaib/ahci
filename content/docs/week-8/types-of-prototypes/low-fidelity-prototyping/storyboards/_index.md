# Storyboards

Storyboards show interaction as a sequence of scenes. They describe user context, goals, actions, system responses, and outcomes.

## Uses

- Explore user journeys.
- Show context of use.
- Communicate design concepts.
- Identify missing steps or assumptions.

## Design Implication

Storyboards are useful before detailed interface design because they keep focus on situation and user goal.
