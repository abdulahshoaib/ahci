# Types of Prototypes

Prototype types differ by fidelity, scope, interactivity, and purpose. Choosing type depends on what designers need to learn.

## Common Types

- Low-fidelity prototypes.
- High-fidelity prototypes.
- Horizontal prototypes.
- Vertical prototypes.

## Design Implication

Wrong prototype type can waste effort or answer wrong question. Match prototype to risk: layout, flow, interaction, content, data, or technical feasibility.
