# Grouping & Alignment

Grouping and alignment are fundamental screen layout principles that help users understand information quickly and reduce cognitive effort.

## Grouping

Grouping means placing related items together and separating unrelated items.

The principle is:

> Logically together → Physically together

Related information should appear close to one another so users can immediately recognize their relationship.

### Examples

**Billing Details**

- Name
- Address
- Credit Card Number

**Delivery Details**

- Name
- Address
- Delivery Time

These sections should be visually separated because they serve different purposes.

Benefits of grouping:

- Improves understanding
- Reduces cognitive load
- Makes forms easier to complete
- Helps users find information quickly

Grouping can be achieved using:

- Boxes
- Headings
- Colours
- Borders
- White space

## Alignment

Alignment refers to arranging interface elements along common visual lines.

Proper alignment improves readability and helps users scan information efficiently.

### Text Alignment

For left-to-right languages, text is usually left-aligned because it matches natural reading patterns.

Benefits:

- Easier reading
- Faster scanning
- Improved consistency

### Name Alignment

When users are searching for surnames, names should be aligned to make comparison easier.

Example:

```text
Dix, Alan
Finlay, Janet
Abowd, Gregory
Beale, Russell
```

This allows users to locate surnames quickly.

### Number Alignment

Numbers should be aligned according to their purpose.

- Right-align integers
- Align decimal points for decimal values

Example:

```text
 627.865
   1.005
 382.583
2502.56
```

This makes numerical comparison much easier.

## Relationship Between Grouping and Alignment

Grouping helps users understand which items belong together.

Alignment helps users compare and scan those items efficiently.

Together, they create screens that are clear, organized, and easy to use.
