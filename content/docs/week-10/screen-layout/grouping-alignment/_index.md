# Grouping & Alignment

Grouping places related items together. Alignment creates visual order and makes relationships easier to scan.

## Good Practice

- Group related controls and content.
- Separate unrelated areas.
- Align labels, fields, and actions.
- Use consistent spacing.
- Preserve visual hierarchy.

## Design Implication

Poor grouping and alignment increase cognitive load because users must infer structure manually.
