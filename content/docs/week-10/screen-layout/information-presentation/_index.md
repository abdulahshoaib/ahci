# Information Presentation

Information presentation controls how data, labels, instructions, and feedback appear to users.

## Principles

- Show information at right time.
- Use clear labels.
- Match format to task.
- Prioritize important details.
- Avoid unnecessary precision or clutter.
- Support comparison when needed.

## Design Implication

Information should help users decide and act. More information is not always better.
