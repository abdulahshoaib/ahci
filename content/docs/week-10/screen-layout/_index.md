# Screen Layout

Screen layout arranges information, controls, and feedback so users can understand and act efficiently.

## Concerns

- Grouping.
- Alignment.
- White space.
- Visual hierarchy.
- Information presentation.
- Colour and aesthetics.
- Localisation.

## Design Implication

Layout should guide attention and reduce effort. Users should not have to search hard for core actions or information.
