# Aesthetics & Colour

Aesthetics refers to the visual appearance of an interface, while colour is one of the most important tools used to create that appearance.

Good visual design can increase user satisfaction and, in some cases, improve productivity. However, visual attractiveness should never reduce usability.

## Aesthetics and Utility

An interface should be both attractive and useful.

Good aesthetics can:

- Improve user satisfaction
- Create positive first impressions
- Make systems more enjoyable to use

However, beauty and usability can sometimes conflict.

Examples:

- Decorative backgrounds may look attractive but make text difficult to read.
- Very clean designs may reduce visual cues needed to distinguish different functions.

The goal is to balance appearance and usability so that visual design supports user tasks rather than distracting from them.

## Colour

Colour should be used carefully and purposefully.

Colour can be used to:

- Highlight important information
- Show relationships between items
- Indicate status or feedback
- Reinforce other visual cues

Guidelines:

- Use colour sparingly
- Do not rely solely on colour to communicate information
- Ensure sufficient contrast between text and background
- Consider users with colour-vision deficiencies

### Poor Use of Colour

Problems occur when:

- Too many colours are used
- Contrast is too low
- Colour is used without a clear purpose
- Information depends entirely on colour differences

A useful test is to view a design in grayscale. If important information becomes unclear, the design relies too heavily on colour.

## 3D Effects

3D effects can help represent physical objects and certain types of data.

They are useful for:

- Physical controls
- Spatial information
- Some graphical visualizations

However, excessive use of 3D effects can reduce readability and clarity.

Examples of poor use include:

- Decorative perspective text
- Unnecessary 3D charts
- Overly complex visual effects

## Design Principle

Colour and aesthetics should reinforce understanding, support usability, and improve the user experience rather than simply making an interface look attractive.
