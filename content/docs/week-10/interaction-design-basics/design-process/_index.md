# Design Process

Design process organizes work from problem understanding to solution refinement. In HCI, process is iterative because user needs and usability problems become clearer through feedback.

## Steps

1. Understand problem and context.
2. Identify users and tasks.
3. Generate design alternatives.
4. Prototype selected ideas.
5. Evaluate and refine.

## Design Implication

Process should support learning and change, not lock team into first idea.
