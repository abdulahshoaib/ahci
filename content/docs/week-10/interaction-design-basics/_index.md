# Interaction Design Basics

Interaction design basics cover how designers move from user needs to usable interfaces. Main concern is making actions, information, and feedback fit user goals.

## Core Ideas

- Understand users and tasks.
- Design around real scenarios.
- Make navigation clear.
- Present information in useful form.
- Iterate through prototype and evaluation.

## Design Implication

Good interaction design joins process, people, and interface details. None works well alone.
