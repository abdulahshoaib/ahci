# Navigation Design

Navigation design focuses on helping users move through a system and find the information or functions they need. Good navigation ensures that users always know where they are, where they can go, and how to reach their goals.

Navigation exists at different levels:

## Local Navigation

Local navigation focuses on a single screen or page.

It considers:

- What options are available from the current screen
- What actions users can perform
- How users move to related screens

The design should help users progress using only local knowledge without needing to understand the entire system structure.

## Global Navigation

Global navigation focuses on the structure of the entire application or website.

It defines:

- Major sections of the system
- Relationships between screens
- Paths between different parts of the application

Global navigation helps users build a mental model of the system.

## Levels of Navigation Design

Navigation can be considered at several levels:

### Widget Level

Individual controls such as:

- Buttons
- Menus
- Links

### Screen Level

Arrangement of controls and information within a screen.

### Application Level

Movement between screens and functional areas.

### Environment Level

Interaction with:

- Other applications
- Operating systems
- External websites and services

## Navigation Structures

### Hierarchical Structure

Organizes information into levels.

Example:

```text
System
├── Information & Help
├── Management
│   ├── Add User
│   └── Remove User
└── Messages
```

Hierarchies are useful for organizing large amounts of information but can become difficult to navigate if they are too deep.

### Network Structure

Allows multiple paths between screens.

A user can move between different parts of the system depending on their task rather than following a strict hierarchy.

Network structures better represent real user workflows and choices.

## Navigating Hierarchies

A common mistake is creating deep hierarchies with many levels.

Deep structures can:

- Increase navigation effort
- Make users lose their place
- Require more memory

A broader and well-organized structure is often easier to navigate than a very deep one.

## Goal Seeking

Users typically navigate with a goal in mind.

Effective navigation should help users:

- Move toward their goal
- Understand available paths
- Avoid confusion and dead ends

Navigation should support progress even when users only have limited knowledge of the system.

## Wider Navigation Context

Navigation is not limited to a single application.

Designers should also consider:

- Links to external systems
- Embedded applications
- Consistency with platform standards
- Data sharing between applications

Good navigation helps users move confidently through a system while maintaining awareness of their location, available options, and destination.
