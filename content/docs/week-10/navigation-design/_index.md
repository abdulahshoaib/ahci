# Navigation Design

Navigation design helps users move through system, understand where they are, and reach goals without getting lost.

## Goals

- Show current location.
- Make available destinations clear.
- Support backtracking and recovery.
- Keep paths predictable.
- Match user task structure.

## Design Implication

Navigation is not decoration. It is part of task support and orientation.
