# Prototyping & Iteration

Prototyping creates testable versions of design ideas. Iteration improves design based on feedback, evaluation, and new understanding.

## Cycle

1. Create prototype.
2. Test with users or experts.
3. Identify problems.
4. Revise design.
5. Test again.

## Design Implication

Iteration turns design from guesswork into learning process. Early prototypes should be cheap enough to change.
