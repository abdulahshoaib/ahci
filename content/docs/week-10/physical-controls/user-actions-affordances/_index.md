# User Actions & Affordances

User actions are the operations users perform to interact with a system, such as entering information, selecting options, clicking buttons, or navigating between screens.

A good interface should make it clear:

- What actions are possible
- Where users can perform them
- How they should be performed

When designing for user actions, information entry should follow a logical structure that matches the user's workflow. Related fields should be grouped together and arranged in a natural order for completion.

Important considerations include:

- Clear labels
- Logical grouping of fields
- Natural input order
- Consistent interaction styles
- Proper keyboard navigation

Users should always be able to distinguish between:

- Active elements (buttons, links, input fields)
- Passive elements (labels, text, information displays)

Consistent visual styles help users identify where they can click, type, or interact.

# Affordances

Affordance is a concept that describes how the appearance of an object suggests the actions that can be performed on it.

For physical objects, shape and form naturally suggest their use.

Examples:

- A door handle suggests pulling
- A button suggests pressing
- A mug handle suggests grasping

In user interfaces, visual appearance can also suggest interaction.

Examples:

- A button-like object suggests clicking
- An icon suggests selection
- A hyperlink suggests navigation

Affordances are influenced by both physical appearance and learned conventions. Users often understand how to interact with interface elements because they resemble familiar objects or follow common design standards.

Good affordances make actions obvious, reduce confusion, and help users understand how to interact with a system without requiring instructions.
