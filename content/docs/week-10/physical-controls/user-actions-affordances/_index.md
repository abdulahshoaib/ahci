# User Actions & Affordances

User actions are what people can do with system. Affordances are action possibilities that object or interface suggests.

## Examples

- Button suggests pressing.
- Slider suggests dragging.
- Handle suggests pulling.
- Text field suggests typing.
- Toggle suggests switching state.

## Design Implication

Perceived affordance matters. If users cannot tell what action is possible, control fails even if technically works.
