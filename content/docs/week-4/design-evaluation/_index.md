# Design Evaluation

Design evaluation checks whether a design supports users and meets its goals. Evaluation can happen with sketches, prototypes, partial systems, or finished products.

## Evaluation Methods

- Usability testing.
- Heuristic evaluation.
- Cognitive walkthrough.
- Expert review.
- Field studies.
- Analytics and usage data.

## Design Implication

Evaluation should happen early and repeatedly. Finding problems before full implementation is cheaper and usually leads to better design.
