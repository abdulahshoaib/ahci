# Interaction Design Activities

Interaction design activities describe the main work designers do when creating interactive systems. These activities are usually iterative, not strictly linear.

## Main Activities

1. Identify needs and establish requirements.
2. Develop alternative designs.
3. Build interactive versions of designs.
4. Evaluate designs with users or experts.

## Design Implication

Good design comes from repeated movement between understanding, making, and evaluating, rather than from a single first solution.
