# User Needs

User needs describe what people require from a system to achieve their goals in a specific context. Needs are not the same as requested features; a feature is one possible way to satisfy a need.

## Identifying Needs

- Observe real tasks.
- Interview users and stakeholders.
- Analyze current tools and pain points.
- Study context of use.
- Look for goals behind feature requests.

## Design Implication

Clear user needs help teams choose useful features, reject unnecessary complexity, and evaluate whether the design solves the right problem.
