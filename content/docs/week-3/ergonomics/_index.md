# Ergonomics

Ergonomics studies how systems fit the physical and cognitive characteristics of people. In HCI, ergonomics helps designers create interfaces and work environments that support comfort, safety, efficiency, and accessibility.

## Physical Ergonomics

Physical ergonomics considers posture, reach, hand movement, fatigue, display position, lighting, and input device placement.

## Cognitive Ergonomics

Cognitive ergonomics considers mental workload, attention, memory demands, decision making, and error prevention.

## Design Implication

Interactive systems should reduce strain, support natural movement, avoid unnecessary workload, and adapt to varied user abilities and contexts.
