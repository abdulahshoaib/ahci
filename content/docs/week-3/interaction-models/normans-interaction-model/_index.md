# Norman's Interaction Model

Norman's interaction model explains interaction as a cycle between a user's goals, actions, system state, and interpretation. It is useful for identifying where users struggle to decide what to do or understand what happened.

## Seven Stages of Action

1. Forming the goal.
2. Forming the intention.
3. Specifying an action.
4. Executing the action.
5. Perceiving the system state.
6. Interpreting the system state.
7. Evaluating the outcome against the goal.

## Design Implication

Interfaces should make possible actions visible, provide clear feedback, and help users connect system results back to their original goals.
