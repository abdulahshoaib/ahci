# Interaction Models

Interaction models describe how users and systems communicate during interaction. They help designers analyze what the user wants, what actions are available, how the system responds, and how the user interprets the result.

## Why Interaction Models Matter

- They expose where confusion or errors may occur.
- They connect user goals with interface actions.
- They help designers reason about feedback and system state.
- They provide vocabulary for evaluating usability problems.

This section covers Norman's Interaction Model, the Abowd and Beale framework, execution and evaluation, and the gulfs that can appear between user intention and system response.
