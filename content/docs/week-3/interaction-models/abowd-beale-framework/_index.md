# Abowd and Beale Framework

The Abowd and Beale framework describes interaction as translation between four components: the user, input, system, and output. Each component has its own language, and interaction problems occur when translations are poor.

## Components

- **User:** The person's goals and task language.
- **Input:** The physical actions or commands used to communicate with the system.
- **System:** The internal processing and system state.
- **Output:** The information presented back to the user.

## Translations

The framework highlights four translations: articulation, performance, presentation, and observation. Good design makes these translations understandable and reliable.
