# Windows, Icons, Menus, and Pointers

Windows, Icons, Menus, and Pointers (WIMP) are the fundamental elements of graphical user interfaces. Together they provide the primary means through which users interact with computer systems.

## Windows

Windows are areas of the screen that behave as if they were independent workspaces.

They can contain:

- Text
- Graphics
- Applications
- Documents

Windows can be:

- Moved
- Resized
- Opened
- Closed

They may overlap each other or be arranged side-by-side (tiled).

### Common Window Components

#### Title Bars

Display the name of the window.

#### Scrollbars

Allow users to move through content vertically or horizontally.

### Types of Window Interfaces

#### Multiple Document Interface (MDI)

Multiple document windows exist inside a single parent application window.

##### Advantages

- Multiple documents can be visible simultaneously
- Coordinated workspace
- Reduced visual clutter
- Only one menu and toolbar set is required

##### Disadvantages

- Menus may change according to the active document
- Child windows are restricted to the parent window
- Increased visual complexity

#### Single Document Interface (SDI)

Each document opens in its own independent window.

##### Advantages

- Document-centered interaction
- Less visually complex
- Each window contains its own menus and tools

##### Disadvantages

- Difficult to group related documents
- Taskbar can become crowded
- Switching between windows may become difficult

#### Tabbed Document Interface (TDI)

Documents are organized using tabs within a single window.

##### Characteristics

- Allows switching between documents using tabs
- Reduces screen clutter
- Combines features of MDI and SDI

## Icons

Icons are small graphical representations of objects, actions, or functions within an interface.

They often represent:

- Applications
- Files
- Folders
- Actions
- Windows

When a window is minimized, it may be represented by an icon.

### Characteristics

- Provide visual representations of system objects
- Can be realistic or highly stylized
- Reduce reliance on text
- Support quick recognition

### Good Icon Design

- Few and meaningful icons
- Simple design
- Easy to recognize
- Avoid unnecessary details

Poorly designed or overly complex icons can confuse users and create frustrating experiences.

## Menus

Menus provide access to system functions and operations through lists of options displayed on the screen.

Users select options using a pointer or other input device.

### Characteristics

- Options may consist of text, symbols, or images
- Frequently used options should appear near the top
- Options may be ordered or unordered
- Menu items should be organized semantically

### Menu Structures

#### Pull-Down Menus

Appear below a menu bar when selected.

#### Cascading Menus

Selecting an option opens another submenu.

#### Pop-Up Menus

Appear only when needed and provide context-sensitive actions.

### Menu Design Recommendations

- Menus should contain at least two options
- Related options should be grouped together
- Use clear and meaningful names
- Maintain consistency in placement and wording
- Inactive options should remain visible
- Frequently used options should be easy to access

## Pointers

A pointer, or cursor, is the visual representation of a pointing device such as a mouse.

The pointer acts as the user's representative within the graphical environment.

### Functions

- Selecting objects
- Activating commands
- Moving items
- Providing contextual information

### Input Devices Used for Pointing

- Mouse
- Trackpad
- Trackball
- Joystick
- Cursor keys
- Keyboard shortcuts

### Characteristics

- Essential for WIMP interaction
- Enables pointing and selection
- Can change appearance to indicate different system states

Example:

A pointer may change to a waiting symbol while the system is processing a task.

### Design Considerations

Pointers should remain easy to locate and distinguish on the screen. If the pointer becomes difficult to see, interaction efficiency can decrease.
