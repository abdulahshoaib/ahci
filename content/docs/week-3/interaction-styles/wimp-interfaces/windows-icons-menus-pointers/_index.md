# Windows, Icons, Menus, and Pointers

The four WIMP components provide the basic structure for many graphical interfaces.

## Windows

Windows separate tasks, documents, or applications into bounded regions.

## Icons

Icons visually represent files, folders, tools, actions, or system states.

## Menus

Menus organize commands and reduce the need to remember exact instructions.

## Pointers

Pointers let users select, drag, resize, and manipulate visible objects.
