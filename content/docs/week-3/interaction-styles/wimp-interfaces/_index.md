# WIMP Interfaces

WIMP stands for windows, icons, menus, and pointers. WIMP interfaces are a major graphical interaction style that supports direct manipulation, visible objects, and multiple tasks on screen.

## Core Elements

- Windows organize applications and documents.
- Icons represent objects, tools, or actions.
- Menus present available commands.
- Pointers allow selection and manipulation.

## Design Implication

WIMP interfaces work well when visual structure, feedback, consistency, and clear object-action relationships are maintained.
