# Menus

Menus are an interaction style that presents users with a set of options displayed on the screen. Instead of remembering commands, users select from visible choices provided by the system.

Because the available options are displayed, menus rely more on recognition than recall, making them easier to use than command-based interfaces.

Users can select options using:

- Numbers
- Letters
- Arrow keys
- Mouse
- A combination of methods (e.g., mouse and keyboard accelerators)

Menus are often organized hierarchically, with related options grouped together. Effective menu design requires sensible grouping and meaningful option names.

Menus are considered a restricted form of a full WIMP interface.

## Characteristics

- Options are visible on the screen
- Reduce the need to memorize commands
- Depend on recognition rather than recall
- Can be organized into hierarchical structures
- Support multiple selection methods

## Advantages

- Easy to learn and use
- Suitable for novice users
- Reduces memory load
- Helps users discover available functionality
- Minimizes typing requirements

## Disadvantages

- Large menus can become complex
- Poor grouping can make options difficult to find
- Deep menu hierarchies may slow navigation
- Can consume significant screen space

## Design Considerations

- Menu names should be meaningful
- Options should be logically grouped
- Frequently used options should be easy to access
- Hierarchical structures should remain simple and understandable
