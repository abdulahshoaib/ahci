# Menus

Menus present a visible set of choices for users to select from. They reduce memory load because users can recognize options instead of recalling commands.

## Strengths

- Easy for beginners to explore.
- Makes available actions visible.
- Supports structured navigation.

## Weaknesses

- Can become slow for expert users.
- Deep menu hierarchies are hard to scan.
- Poor labels can make options difficult to understand.
