# Interaction Styles

Interaction styles are common ways users communicate with computer systems. Each style has strengths, weaknesses, and suitable contexts.

## Common Styles

- Command line interfaces
- Menus
- Natural language interfaces
- Query interfaces
- Form-fill interfaces
- Spreadsheets
- WIMP interfaces

## Design Implication

Choosing an interaction style affects learnability, speed, error rates, flexibility, and the level of user expertise required.
